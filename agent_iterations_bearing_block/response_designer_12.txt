## Next Step: Use build123d's Native Fillet Operation

Abandon the cone approach entirely. Use `fillet()` on the **edges where the housing meets the top face of the base**. Here's the correct approach:

```python
from build123d import *

# Base plate
base = Box(100, 30, 10)

# Housing cylinder - center at z=0 for build123d (centered by default)
# Base top face is at z=5, housing should extend from z=5 to z=45
# So housing center is at z=5+20=25 from world origin... 
# but Box is centered at z=0, so base top = z=5
# Cylinder centered, so translate center to z = 5 + 20 = 25

housing_outer = Cylinder(25, 40).translate((0, 0, 25))

# Union base and housing
pillow_block = base + housing_outer

# Now fillet the circular edges where housing meets base top face
# These are the edges at z=5 on the cylindrical housing
# Select edges at the junction height
edges_to_fillet = pillow_block.edges().filter_by_position(
    Axis.Z, 4.9, 5.1
).filter_by(GeomType.CIRCLE)

pillow_block = fillet(edges_to_fillet, radius=5)

# Bore through housing
bore = Cylinder(15, 52).translate((0, 0, 20))

# Mounting holes
hole1 = Cylinder(5, 12).translate((40, 0, 0))
hole2 = Cylinder(5, 12).translate((-40, 0, 0))

pillow_block = pillow_block - bore - hole1 - hole2

OBJ = pillow_block
```

**Key points:**
- Filter edges at `z ≈ 5` (top of base) that are circular
- Apply `fillet(edges, radius=5)` natively
- Do the fillet **before** subtracting the bore so geometry is cleaner
