## Next Step: Fix the Fillet with Build123d's Builder API

The imperative API fillet selector is unreliable here. **Switch to the Builder (Context) API** for reliable fillet application:

```python
from build123d import *

with BuildPart() as pb:
    # Base
    Box(100, 30, 10)
    # Housing
    with Locations((0, 0, 5)):
        Cylinder(25, 40, align=(Align.CENTER, Align.CENTER, Align.MIN))
    # Fillet the junction edges
    fillet(
        pb.part.edges().filter_by(GeomType.CIRCLE).filter_by_position(
            Axis.Z, 4.5, 5.5
        ),
        radius=5
    )
    # Bore
    with Locations((0, 0, 5)):
        Cylinder(15, 52, align=(Align.CENTER, Align.CENTER, Align.MIN), mode=Mode.SUBTRACT)
    # Mounting holes
    with Locations((40, 0, 5), (-40, 0, 5)):
        Cylinder(5, 12, align=(Align.CENTER, Align.CENTER, Align.MIN), mode=Mode.SUBTRACT)

OBJ = pb.part
```

**Key advantages:**
- `Align.MIN` ensures cylinders grow upward from base top
- Fillet is applied **before** subtracting bore (simpler topology)
- Builder API manages context automatically — no manual edge hunting needed
