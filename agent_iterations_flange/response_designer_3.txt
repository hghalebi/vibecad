## Next Step: Fix the Horizontal Flange Holes

The horizontal flange lies in the **XZ plane** (Y=0 to Y=3mm). Holes must be cylinders oriented along **Y-axis**, positioned at:
- X = `hole_pos1` (12.5) and X = `hole_pos2` (37.5)  
- Z = `hole_inset` (9mm from front face, so Z = 9)
- Height must pass through 3mm thickness

**Replace the horizontal hole cylinders with this approach:**

```python
# Horizontal flange holes — drill through Y (thickness direction)
# Rotate cylinder 90° around X to align with Y-axis
h_hole1 = (
    Pos(hole_pos1, 0, hole_inset) 
    * Rot(90, 0, 0) 
    * Cylinder(hole_dia/2, thickness * 2,
               align=(Align.CENTER, Align.CENTER, Align.MIN))
)

h_hole2 = (
    Pos(hole_pos2, 0, hole_inset) 
    * Rot(90, 0, 0) 
    * Cylinder(hole_dia/2, thickness * 2,
               align=(Align.CENTER, Align.CENTER, Align.MIN))
)
```

**Key changes:**
- `Rot(90, 0, 0)` rotates cylinder to drill along **Y-axis** (through the 3mm flange thickness)
- Z position = `hole_inset = 9mm` (9mm from the front edge of horizontal flange)
- X positions remain at 12.5 and 37.5mm

This will give you **2 holes on each flange** (4 total), symmetrically placed — correct industry practice for an angle bracket.
