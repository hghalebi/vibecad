- But the `Pos` + `Rot` approach seems to be failing silently — simplify using direct cylinder placement.

## Next Step: Fix the Mounting Holes

Replace the complex `h_hole`/`v_hole` functions with straightforward axis-aligned cylinders using correct positions and orientations:

```python
from build123d import *

flange_length = 50
flange_width  = 50
thickness     = 3
hole_dia      = 5
hole_inset    = 9

# Build L-profile points
pts = [
    (0, 0), (flange_length, 0), (flange_length, thickness),
    (thickness, thickness), (thickness, flange_length), (0, flange_length), (0, 0)
]
wire = Wire.make_polygon([Vector(p[0], p[1], 0) for p in pts])
profile = make_face(wire)
bracket = extrude(profile, flange_width)

# --- HORIZONTAL FLANGE HOLES (pierce Y: 0→3, flange in XZ plane) ---
# Holes at (hole_inset, mid_Z) and (flange_length-hole_inset, mid_Z)
mid_z = flange_width / 2  # Z midpoint = 25

h_cyl1 = Pos(hole_inset,          -1, mid_z) * Rot(90, 0, 0) * Cylinder(
    hole_dia/2, thickness + 2,
    align=(Align.CENTER, Align.CENTER, Align.MIN))

h_cyl2 = Pos(flange_length - hole_inset, -1, mid_z) * Rot(90, 0, 0) * Cylinder(
    hole_dia/2, thickness + 2,
    align=(Align.CENTER, Align.CENTER, Align.MIN))

# --- VERTICAL FLANGE HOLES (pierce X: 0→3, flange in YZ plane) ---
v_cyl1 = Pos(-1, hole_inset,          mid_z) * Rot(0, -90, 0) * Cylinder(
    hole_dia/2, thickness + 2,
    align=(Align.CENTER, Align.CENTER, Align.MIN))

v_cyl2 = Pos(-1, flange_length - hole_inset, mid_z) * Rot(0, -90, 0) * Cylinder(
    hole_dia/2, thickness + 2,
    align=(Align.CENTER, Align.CENTER, Align.MIN))

bracket = bracket - [h_cyl1, h_cyl2, v_cyl1, v_cyl2]

# --- INNER EDGE FILLET ---
inner_edges = (bracket.edges()
    .filter_by(Axis.Z)
    .filter_by_position(Axis.X, thickness - 0.01, thickness + 0.01)
    .filter_by_position(Axis.Y, thickness - 0.01, thickness + 0.01))

bracket = bracket.fillet(1.5, inner_edges)

OBJ = bracket
```

**Key fix:** The `Rot(90,0,0)` rotates the cylinder so it points along **Y** (piercing the horizontal flange), and `Rot(0,-90,0)` points it along **X** (piercing the vertical flange). The `Pos` starts 1mm outside the face to guarantee clean boolean cuts. This should produce clearly visible holes in both flanges.
