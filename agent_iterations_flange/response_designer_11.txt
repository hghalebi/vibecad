## Next Step: Add Outer Edge Chamfers/Fillets

For a proper sheet metal bracket, add small chamfers (0.5mm) or fillets (0.5mm) on all the **outer long edges** (the sharp exterior corners running along the Z-axis). This is standard practice for deburring sheet metal parts.

**Specific instruction to the coding agent:**

```python
# After the inner fillet, add outer edge treatment
# Select all Z-parallel edges on the OUTER corners of the bracket
# These are the 4 long edges running in Z-direction on outer faces

outer_edges = (
    bracket.edges()
    .filter_by(Axis.Z)
    .filter_by_position(Axis.X, -0.01, 0.01)  # X=0 outer edge
    | bracket.edges()
    .filter_by(Axis.Z)
    .filter_by_position(Axis.X, flange_length - 0.01, flange_length + 0.01)  # X=50 edge
    | bracket.edges()
    .filter_by(Axis.Z)
    .filter_by_position(Axis.Y, flange_length - 0.01, flange_length + 0.01)  # Y=50 edge
)

bracket = bracket.fillet(0.5, outer_edges)
```
